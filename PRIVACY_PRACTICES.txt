==============================================
Chrome Web Store「プライバシーへの取り組み」タブ 入力内容
==============================================

■■■ 1. 単一用途の説明（Single Purpose） ■■■

この拡張機能は、不動産サイト（SUUMO、三井のリハウス、アットホーム、ホームズ）のページに表示されている物件の価格と専有面積を読み取り、坪単価・平米単価・月額概算・価格変動を表示するとともに、ユーザーが閲覧した物件内で同じ建物・住戸を照合します。物件比較を効率化することが唯一の目的です。

---または（より簡潔な版）---

不動産サイトの物件ページで、価格と専有面積から坪単価・平米単価・月額概算・価格変動を表示し、閲覧履歴内の同じ建物・住戸の掲載差を比較しやすくします。

==============================================

■■■ 2. ホスト権限の使用理由（Host Permission Justification） ■■■

この拡張機能は、以下の不動産サイトで物件情報を表示するために host_permissions を使用します：

• *.suumo.jp
• *.rehouse.co.jp
• *.athome.co.jp
• *.homes.co.jp

各サイトのDOM（ページ内容）から物件の価格テキスト（例：「5,980万円」）と専有面積テキスト（例：「75.5㎡」）、管理費・修繕積立金などの公開情報を読み取り、坪単価・平米単価・月額概算・価格変動を計算してページに表示要素を追加するために必要です。

すべての計算・保存・横断照合処理はユーザーのブラウザ内で完結し、本拡張機能の開発者サーバー、外部サーバー、分析サービスへデータを送信することは一切ありません。横断照合のために未閲覧サイトを巡回したり、未閲覧サイトへリクエストしたりしません。対応不動産サイトへのページ取得は、保存済みお気に入りの定期的な価格・掲載状態の再チェックと、ユーザーが開始したCSVエクスポートで一覧からリンクされた詳細ページを取得する場合に行います。

==============================================

■■■ 2-2. alarms 権限の使用理由（Alarms Permission Justification） ■■■

お気に入りに保存した物件の価格・掲載状態を定期的に再チェックするために使用します。再チェックは6時間ごとに起動し、24時間以上確認していない物件を少数ずつ確認します。

==============================================

■■■ 2-3. storage 権限の使用理由（Storage Permission Justification） ■■■

お気に入り、メモ、価格履歴、掲載状態、ローン条件、表示条件、リリースノート既読状態に加え、閲覧物件のローカル索引、手動の同一/別判定、住所の街区単位の建物名別名、横断照合設定をユーザーのブラウザ内に保存するために使用します。新しい権限は追加せず、保存データは外部サーバーへ送信しません。

==============================================

■■■ 3. リモートコードの使用理由（Remote Code Justification） ■■■

この拡張機能はリモートコードを使用しません。

すべてのコード（`property-matcher.js`、`observed-listings-store.js`、`content.js`、`background.js` など）は拡張機能パッケージに含まれており、外部からコードを読み込むことはありません。

---または（チェックボックス形式の場合）---

☑ この拡張機能はリモートコードを使用しません

==============================================

■■■ 4. データの使用に関する表明（Data Usage Certification） ■■■

☑ この拡張機能は、限定的な使用の開示要件に従ってユーザーデータを処理します

☑ この拡張機能は、承認された使用例に記載されていない方法でユーザーデータを収集、使用、または送信しません

---詳細説明（必要な場合）---

この拡張機能のデータ処理：

処理するデータ：
• 閲覧した不動産物件のURL、サイト、物件・建物名、住所、価格、専有面積、間取り、階数、費用（管理費・修繕積立金）、仲介会社、掲載状態、確認日時（初回・最終閲覧、掲載確認）（公開情報のみ）
• ユーザーが保存したお気に入りURL、メモ、ローン条件
• ユーザーが保存した同一物件／別物件の手動判定、住所の街区単位で確認した建物名の別名

データの使用目的：
• 坪単価・平米単価の計算
• 月額概算の計算
• お気に入り物件の価格変動・掲載状態の確認
• 閲覧履歴内にある同じ建物・住戸の照合と掲載差の比較
• 計算結果のページ表示

データの保存：
• 計算効率化のため、価格と面積の組み合わせをブラウザのメモリ内に一時キャッシュ（ページを閉じると消去）
• お気に入り、メモ、価格履歴、掲載状態、ローン条件、表示条件、リリースノート既読状態、閲覧物件のローカル索引、手動判定、建物名別名、横断照合設定を chrome.storage.local に保存
• お気に入り以外の閲覧物件は最終確認から90日・最大500件で保持。お気に入りは保持期限・件数制限の対象外
• ポップアップから横断照合を無効化し、横断照合データだけを削除可能（お気に入りは削除されません）

データの送信：
• 本拡張機能の開発者サーバー、外部サーバー、分析サービスへのデータ送信は一切行いません
• 横断照合のために未閲覧サイトへの巡回・リクエストは行いません
• 保存済みお気に入りの定期的な価格・掲載状態の再チェックでは、保存済み物件URLに対して対象不動産サイトのページ取得リクエストを行います
• ユーザーが開始したCSVエクスポートでは、一覧からリンクされた詳細ページを対象不動産サイトから取得します

個人情報：
• 個人を特定できる情報は一切収集しません

==============================================

■■■ トラブルシューティング ■■■

もし「リモートコード」に関するエラーが出る場合：

1. manifest.json を確認
   - externally_connectable がないことを確認
   - content_security_policy で外部スクリプトを許可していないことを確認

2. プライバシーへの取り組みタブで明示的に宣言
   - 「リモートコードを使用しない」を選択
   - または上記の説明文を入力
