==============================================
Chrome Web Store「プライバシーへの取り組み」タブ 入力内容
==============================================

■■■ 1. 単一用途の説明（Single Purpose） ■■■

この拡張機能は、不動産サイト（SUUMO、三井のリハウス、アットホーム、ホームズ）のページに表示されている物件の価格と専有面積を読み取り、坪単価と平米単価を計算してページ上に表示します。物件比較を効率化することが唯一の目的です。

---または（より簡潔な版）---

不動産サイトの物件ページで、価格と専有面積から坪単価・平米単価を自動計算して表示し、物件比較を効率化します。

==============================================

■■■ 2. ホスト権限の使用理由（Host Permission Justification） ■■■

この拡張機能は、以下の不動産サイトで物件情報を表示するために host_permissions を使用します：

• *.suumo.jp
• *.rehouse.co.jp
• *.athome.co.jp
• *.homes.co.jp

各サイトのDOM（ページ内容）から物件の価格テキスト（例：「5,980万円」）と専有面積テキスト（例：「75.5㎡」）を読み取り、坪単価・平米単価を計算してページに表示要素を追加するために必要です。

すべての処理はユーザーのブラウザ内で完結し、読み取ったデータを外部に送信することは一切ありません。

==============================================

■■■ 3. リモートコードの使用理由（Remote Code Justification） ■■■

この拡張機能はリモートコードを使用しません。

すべてのコード（content.js、styles.css）は拡張機能パッケージに含まれており、外部からコードを読み込むことはありません。

---または（チェックボックス形式の場合）---

☑ この拡張機能はリモートコードを使用しません

==============================================

■■■ 4. データの使用に関する表明（Data Usage Certification） ■■■

☑ この拡張機能は、限定的な使用の開示要件に従ってユーザーデータを処理します

☑ この拡張機能は、承認された使用例に記載されていない方法でユーザーデータを収集、使用、または送信しません

---詳細説明（必要な場合）---

この拡張機能のデータ処理：

収集するデータ：
• 不動産サイトのページ上に表示されている物件の価格と専有面積のテキスト（公開情報のみ）

データの使用目的：
• 坪単価・平米単価の計算
• 計算結果のページ表示

データの保存：
• 計算効率化のため、価格と面積の組み合わせをブラウザのメモリ内に一時キャッシュ（ページを閉じると消去）
• 永続的なストレージへの保存は行いません

データの送信：
• 外部サーバーへのデータ送信は一切行いません
• すべての処理はユーザーのブラウザ内で完結します

個人情報：
• 個人を特定できる情報は一切収集しません

==============================================

■■■ 5. 認定データ使用（Certified Data Use） ■■■

【収集するデータ】
なし（個人を特定できるデータは収集しません）

【データハンドラー】
なし

【データの使用目的】
☑ ウェブサイトのコンテンツを変更する目的でのみ使用
（物件情報の計算結果を表示するため）

==============================================

■■■ トラブルシューティング ■■■

もし「リモートコード」に関するエラーが出る場合：

1. manifest.json を確認
   - externally_connectable がないことを確認
   - content_security_policy で外部スクリプトを許可していないことを確認

2. プライバシーへの取り組みタブで明示的に宣言
   - 「リモートコードを使用しない」を選択
   - または上記の説明文を入力

==============================================

これらの内容を「プライバシーへの取り組み」タブの各フィールドにコピー＆ペーストしてください。
