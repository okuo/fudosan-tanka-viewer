# 不動産坪単価・平米単価表示 Chrome拡張

SUUMO、三井のリハウス、アットホーム、ホームズの物件ページに坪単価と平米単価を自動計算して表示するChrome拡張機能です。

## 機能

- 物件価格と専有面積から**坪単価**と**平米単価**を自動計算
- 物件価格の直下に目立つスタイルで表示
- 一覧ページ・詳細ページの両方に対応
- **一覧ページの月々概算表示**: 保存したローン条件でローン返済額を表示。管理費・修繕積立金が取得できる場合は合算
- **詳細ページの月額コスト概算**: ローン返済額+管理費+修繕積立金の合計月額を表示
- **住宅ローン条件の保存**: ポップアップまたは詳細ページのシミュレーションで設定した金利・返済年数・頭金を保存
- **価格改定ウォッチ**: お気に入り物件の価格を再訪時に比較し、値下がり・値上がりを表示
- **お気に入り自動再チェック**: お気に入り物件の価格と掲載状態を定期確認し、掲載終了の可能性も表示
- **価格推移グラフ**: お気に入り物件の価格履歴をポップアップ内でミニグラフ表示
- **リリースノート表示**: 更新後にWhat's Newを表示し、バージョン表示から履歴を確認可能
- **更新バッジ表示**: 更新後は拡張アイコンにNEWバッジを表示し、What's New確認後に自動で消去
- **お気に入り機能**: 「坪たんに登録」ボタンでサイト横断保存し、価格改定順・価格順・坪単価順で並び替え
- **4サイト横断・同一物件比較**: 対応4サイトで閲覧した物件をローカル照合し、同じマンション・住戸の掲載差をSide Panelで比較
- **メモ機能**: お気に入り物件ごとに検討メモを保存
- **バージョン表示**: 拡張機能アイコンをクリックするとポップアップ上部に現在バージョンを表示
- 無限スクロールにも自動対応
- **CSVエクスポート**: 対応4サイトの一覧ページから物件データを一括ダウンロード

## 表示例

```
坪単価: 250万円/坪 | 平米単価: 75万円/㎡
月々概算 約18.2万円 ローンのみ 0.8%/35年
価格改定検知: 値下がり -300万円
```

## インストール方法

### 開発版（ローカルインストール）

1. このリポジトリをクローンまたはダウンロード

2. **アイコン画像を準備**
   `icons/` フォルダに以下の画像を配置：
   - `icon16.png` (16x16px)
   - `icon32.png` (32x32px)
   - `icon48.png` (48x48px)
   - `icon128.png` (128x128px)

   詳細は `icons/README.md` を参照

3. ローカル確認用ビルドを作成

   ```bash
   bash scripts/build-local.sh
   ```

   `dist/local` にはStore版と見分けやすいローカル版が生成されます。拡張機能名は `坪たん LOCAL`、ポップアップ上部は `LOCAL v...`、ツールバーの拡張アイコンには `DEV` バッジが表示されます。

4. Chromeで拡張機能を読み込む
   - `chrome://extensions/` を開く
   - 右上の「デベロッパーモード」をON
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - `dist/local` フォルダを選択

5. 対応サイトの物件ページにアクセスして動作確認
   - SUUMO: https://suumo.jp/ms/chuko/tokyo/
   - 三井のリハウス: https://www.rehouse.co.jp/buy/mansion/
   - アットホーム: https://www.athome.co.jp/mansion/chuko/
   - ホームズ: https://www.homes.co.jp/mansion/chuko/

## CSVエクスポート機能

### 機能概要

一覧ページの「📊 CSVエクスポート」ボタンから、表示中の全物件データをCSV形式でダウンロードできます。SUUMO、三井のリハウス、アットホーム、ホームズに対応しています。

### 取得データ

- **基本情報**: 物件名、住所、価格、専有面積、坪単価、平米単価、間取り、築年数、駅距離、URL
- **詳細情報**（詳細ページから自動取得・28項目）: 階数、向き、管理費、修繕積立金、総戸数、構造、駐車場、築年月、不動産会社名 など
- **取得ステータス**: 詳細ページ取得の成功・失敗・URLなしをCSVに出力

### 対応状況

- ✅ **SUUMO**: 一覧・詳細情報取得に対応
- ✅ **三井のリハウス**: 一覧・詳細情報取得に対応
- ✅ **アットホーム**: 一覧・詳細情報取得に対応
- ✅ **ホームズ**: 一覧・詳細情報取得に対応

詳細ページから取得できない項目は空欄になります。詳細取得に失敗した物件も、一覧ページで取得できた情報だけでCSVに含めます。

## 住宅ローン・月額コスト

ポップアップの「ローン条件」から、金利・返済年数・頭金を保存できます。保存した条件は一覧ページの月々概算、詳細ページの月額コスト概算、住宅ローンシミュレーションに反映されます。

- デフォルト: 金利0.8%、35年返済、頭金0円
- 一覧ページ: ローン返済額を表示。管理費・修繕積立金が物件カード内から取得できる場合は合算
- 詳細ページ: ローン返済額+管理費+修繕積立金を合算
- 条件は `chrome.storage.local` に保存され、外部サーバーには送信されません

## 価格改定ウォッチ

お気に入りに追加した物件は、再訪時またはバックグラウンド再チェック時に現在価格と前回確認価格を比較します。

- 値下がり・値上がりをページ上とポップアップに表示
- 価格履歴をポップアップ内のミニグラフで表示
- 掲載終了の可能性、確認失敗、掲載中の状態をポップアップに表示
- ポップアップから手動で再チェック可能
- `currentPrice`, `previousPrice`, `priceHistory`, `lastCheckedAt`, `listingStatus`, `lastAutoCheckedAt` をローカル保存
- ポップアップで「価格改定が新しい順」に並び替え可能

バックグラウンド再チェックは6時間ごとに起動し、24時間以上確認していないお気に入りを最大5件ずつ確認します。各物件の取得間隔を空け、対象サイトへの負荷を抑えます。

## 4サイト横断・同一物件比較

SUUMO、三井のリハウス、アットホーム、ホームズで実際に閲覧した物件情報を正規化し、`chrome.storage.local` のローカル索引に保存します。保存対象は物件URL、サイト、物件・建物名、住所、価格、専有面積、間取り、階数、管理費、修繕積立金、仲介会社、掲載状態、確認日時です。対応サイト上のすべての掲載を網羅する機能ではありません。

- 照合は建物を先に判定し、その建物内で住戸を判定します。高信頼度の自動照合には住所の街区一致が必要です
- ユーザーが「同じ」「別」と保存した手動判定は自動判定より優先され、住所の街区単位で確認した建物名の別名もローカル保存されます
- バージョン1.12.0より前に保存したお気に入りは、更新後に一度だけローカル索引へ取り込みます。「横断データを削除」してもお気に入り自体は削除せず、移行済みマーカーにより削除後に自動で再作成されません
- お気に入り以外の閲覧物件は最終確認から90日で期限切れとなり、最大500件に制限されます。お気に入りは期限・件数制限の対象外です
- 照合は閲覧履歴内だけで行い、未閲覧サイトを巡回・取得しません。横断照合データを外部サーバーや分析サービスへ送信することもありません
- ポップアップから横断照合を停止したり、横断データだけを削除したりできます

実装は正規化・照合を担う `property-matcher.js` と、保持期限・件数制限・手動判定を担う `observed-listings-store.js` に分かれています。ユーザーデータ／設定の4キーは `observedListingsV1`、`listingMatchOverridesV1`、`buildingAliasesV1`、`crossSiteMatchingSettingsV1` です。Side Panelを開くための `crossSitePendingSelectionV1` は一時キー、`crossSiteMigrationsV1` はお気に入り移行を管理する内部キーです。

## リリースノート

拡張機能の更新後、ポップアップを開いた初回にWhat's Newを表示します。閉じると次のバージョン更新まで自動表示されません。ポップアップ上部のバージョン表示から、いつでも最近の更新内容を確認できます。

更新後はツールバーの拡張アイコンに `NEW` バッジを表示します。What's Newを閉じるとバッジも消えます。

## 技術仕様

- **Manifest Version**: 3
- **対象サイト**:
  - `*.suumo.jp`
  - `*.rehouse.co.jp`
  - `*.athome.co.jp`
  - `*.homes.co.jp`
- **計算式**:
  - 坪単価 = 物件価格 ÷ (専有面積㎡ ÷ 3.3058)
  - 平米単価 = 物件価格 ÷ 専有面積㎡
  - 月額ローン返済額（元利均等） = 借入額 × 月利 × (1+月利)^返済月数 ÷ ((1+月利)^返済月数 - 1)
- **表示**: 整数（四捨五入）
- **バックグラウンド再チェック**: Chrome alarmsで定期実行し、対象サイトの詳細ページから公開情報のみを再確認

通常のGoogle Chrome安定版は自動拡張ロード用フラグの一部が制限されることがあります。ローカルで実際のChromeプロファイルに読み込んだ拡張を確認したい場合は、Chrome拡張を手動で読み込んだうえで、CodexのChrome操作からタブ・ポップアップの手動相当テストを行うのが向いています。

## リリース自動化

`v*.*.*` タグをPushすると、GitHub Actionsでzipを作成し、GitHub Releaseへ添付します。Chrome Web Store連携のSecretsが揃っている場合は、Chrome Web Store API v2でパッケージをアップロードし、`publish` APIで審査提出まで自動実行します。

### 必須Secrets

| Secret | 用途 |
|--------|------|
| `EXTENSION_ID` | Chrome Web Store の拡張機能ID |
| `CWS_PUBLISHER_ID` | Chrome Web Store のパブリッシャーID |
| `CWS_CLIENT_ID` | Google OAuth Client ID |
| `CWS_CLIENT_SECRET` | Google OAuth Client Secret |
| `CWS_REFRESH_TOKEN` | Google OAuth Refresh Token |

### 任意Variables

| Variable | デフォルト | 用途 |
|----------|------------|------|
| `CWS_AUTO_PUBLISH` | `true` | `false` にするとアップロードのみで審査提出しない |
| `CWS_PUBLISH_TYPE` | `DEFAULT_PUBLISH` | `STAGED_PUBLISH` にすると承認後に手動公開待ちにする |
| `CWS_BLOCK_ON_WARNINGS` | `true` | 警告がある場合に審査提出を失敗させる |
| `CWS_SKIP_REVIEW` | `false` | 審査スキップを試す場合のみ `true` |
| `CWS_DEPLOY_PERCENTAGE` | 未指定 | 初期ロールアウト率を指定する場合に設定 |

## プライバシーポリシー

この拡張機能は**個人情報を一切収集しません**。

### データ処理について

- すべての計算処理はブラウザ内でローカルに実行されます
- 本拡張機能の開発者サーバーや分析サーバーへデータを送信することは一切ありません
- 物件の価格、面積、管理費、修繕積立金などを読み取り、計算結果をページに表示します
- お気に入り、メモ、価格履歴、掲載状態、ローン条件、表示条件に加え、閲覧物件のURL・サイト・物件/建物名・住所・価格・専有面積・間取り・階数・管理費・修繕積立金・仲介会社・掲載状態・確認日時、手動の同一/別判定、住所の街区単位の建物名別名を `chrome.storage.local` にローカル保存します
- 横断照合用の非お気に入りデータは90日・最大500件で保持し、お気に入りはこの制限の対象外です。ポップアップから照合の停止と横断データの削除ができます
- 横断照合は閲覧履歴内だけで行い、未閲覧サイトへの巡回・リクエストは行いません
- お気に入り再チェック時のみ、保存済み物件URLに対して対象不動産サイトのページを取得します
- Cookieは使用しません

### 使用する権限

この拡張機能は以下の権限を使用します：

- `*.suumo.jp` - SUUMOサイトで坪単価を表示
- `*.rehouse.co.jp` - 三井のリハウスサイトで坪単価を表示
- `*.athome.co.jp` - アットホームサイトで坪単価を表示
- `*.homes.co.jp` - ホームズサイトで坪単価を表示
- `storage` - お気に入り、メモ、価格履歴、ローン条件、表示条件、閲覧物件のローカル索引、手動照合判定をブラウザ内に保存
- `alarms` - お気に入り物件の価格・掲載状態を定期再チェックするために使用

これらの権限は、各サイトのページ内容（物件価格、専有面積、管理費、修繕積立金など）を読み取り、計算結果を表示し、ユーザー設定をブラウザ内に保存するためにのみ使用されます。

詳細は [プライバシーポリシー](PRIVACY_POLICY.md) をご覧ください。
